# EduOrbit: five-minute demo script

Open the demo (`npm run demo` or the GitHub Pages preview). Log in as **aarav@eduorbit.demo / demo1234**. Aarav's nine days of history were produced by replaying real lessons, answers and study sessions through the same engine the server runs, so every number on screen is earned, not typed in.

| # | Do | Say | Time |
|---|---|---|---|
| 1 | Landing page, scroll once | "Four subjects only: Physics, Chemistry, Mathematics, Biology. School, JEE and NEET paths. Free by design." | 0:20 |
| 2 | Log in as Aarav | "Dashboard: streak, coins, XP, study time, accuracy and chapters are all read from server-written documents. New students see an empty state, never fake numbers." | 0:50 |
| 3 | Point at Strengths and Needs practice | "Strong, Good, Needs Practice, Weak come from a documented mastery formula: difficulty-weighted accuracy, assessments, coverage, recency, repeated mistakes. Opening a page changes nothing." | 1:10 |
| 4 | Click Recommended next | "It picks the weakest rated topic and says why." | 1:25 |
| 5 | Learn → Class 9 → Physics → Motion → Equations of Motion | "Chapter structure is NCERT-aligned for all four subjects and classes. Chapters without authored content say so honestly." | 1:50 |
| 6 | Learn tab: read the concept, mark the lesson complete | "XP toast. Lesson completion is a server event; finishing every lesson in a chapter pays a chapter bonus." | 2:10 |
| 7 | Practice tab: answer one question wrong, then one right | "Grading happens on the server against a private answer key. Wrong shows the explanation and pays nothing. First correct attempt pays once; repeats never pay again." | 2:45 |
| 8 | OrbitAI tab: Explain, then Explain again, then Hint | "OrbitAI knows the class, chapter and topic. Ask the same concept twice and it changes approach. Hint mode never reveals the answer. In the demo the AI key is absent, so answers come from authored content and are labelled as such." | 3:20 |
| 9 | Assessments: start the Daily Assessment, answer a few, submit | "Papers are built on the server, one per day. Result shows strong and weak topics with recommendations, and updates mastery." | 3:40 |

| 11 | Calendar: click a green day | "Study time, questions, accuracy, lessons, topics, XP and coins per day." | 4:30 |

| 13 | Resize to phone width or open on a phone | "Bottom navigation, drawer menu, same features." | 5:00 |
